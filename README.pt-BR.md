# Laboratório de E-mail Protheus

<br />

[English](README.md) &nbsp;|&nbsp; **Português (Brasil)**

<br />

Exemplos em ADVPL para envio de e-mails no TOTVS Protheus — integração SMTP, templates HTML e anexos de arquivos.

> **Aviso Legal**: Exemplos educacionais. Todos os endereços de servidores, credenciais e contas de e-mail são fictícios.

## Exemplos

### Envio SMTP
Envio básico de e-mail via SMTP com autenticação.
  

### Template HTML
E-mail em formato HTML dinâmico com dados de tabelas do Protheus.
  

### Anexos
E-mail com anexos em PDF/XML gerados a partir de dados do ERP.
