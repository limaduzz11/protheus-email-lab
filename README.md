# Protheus Email Lab

<br />

**English** &nbsp;|&nbsp; [Português (Brasil)](README.pt-BR.md)

<br />

ADVPL examples for sending emails from TOTVS Protheus — SMTP integration, HTML templates, and file attachments.

> **Disclaimer**: Educational examples. All server addresses, credentials, and email accounts are fictional.

## Examples

### SMTP Send
Basic email sending via SMTP with authentication.
`ADVPL` `SMTP` `Email`

### HTML Template
Rich HTML email with dynamic data from Protheus tables.
`ADVPL` `HTML` `Email`

### Attachment
Email with PDF/XML file attachments generated from Protheus data.
`ADVPL` `SMTP` `File`

## Tech Stack

`ADVPL` `TOTVS Protheus` `SMTP` `Email`
